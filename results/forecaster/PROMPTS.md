# Exact prompts given to the three forecaster subagents (13 Nov 2026)

One prompt per capsule. The three prompts were identical except for the year (1995, 2005 or 2010) in the folder path,
the database file name and the `capsule-<year>` name. The 1995 prompt is reproduced verbatim below. Nothing else was
sent to the agents: no repo, no backtest results, no hint about which signal to use. (The home folder in the paths is
shortened to `~` here; nothing else is changed.)

The method hints that are present are exactly these two sentences: "Start by inspecting the schema (labels, properties,
relationship types) with a few queries, then decide how to rank pairs." and "choose your own method for ranking, using
what you find in the data." The brief itself (`BRIEF_<year>.md`, generated by `prometheus capsule`) names the node and
relationship types and says "return the 10 pairs of fields you think are most likely to combine for the first time", with
no method. The brief does say pairs "must not already be connected by COMBINED_WITH". The agents' choice of shared
combination partners was theirs, but the schema they were shown contains `COMBINED_WITH` and `BUILDS_ON` only, so the
space of obvious methods was small.

The helper they used is `query_helper.py` (copied to each folder as `query.py`): it speaks the Relate MCP protocol to
`relate serve --mcp stdio --database <capsule> --read-only` and calls its `read_cypher` tool.

## Prompt (1995)

You are a forecaster in a blinded experiment. Your working folder is ~/prometheus-forecaster/1995 and nothing else. Do not read, list or open any file or directory outside that folder (no parent folders, no home directory, no other projects), do not browse the web, and do not use any tool on the database except the helper below. The folder holds BRIEF.md (your task), 1995.rl (the database), and query.py (a read-only query helper).

Step 1: read ~/prometheus-forecaster/1995/BRIEF.md and follow it exactly.
Step 2: query the database ONLY with: cd ~/prometheus-forecaster/1995 && python3 query.py 'YOUR CYPHER' (you may pass several queries in one call). This is the read-only Cypher tool of the `capsule-1995` database; it refuses writes. Start by inspecting the schema (labels, properties, relationship types) with a few queries, then decide how to rank pairs.
Step 3: choose your own method for ranking, using what you find in the data. Work out your own reasoning; do not guess what the fields are, names are hidden.
Step 4: your final reply must be ONLY the JSON object the brief asks for, with exactly 10 pairs, each with a, b, the exact Cypher query that supports it, and a one-sentence why. No other text before or after it, no code fences. Pairs must not already be connected by COMBINED_WITH; verify that with a query before you include a pair.

## Caveat on the saved forecasts

The 1995 and 2010 forecast files were re-typed by the orchestrating session from the agents' returned JSON, not copied byte
for byte (the 2005 file was pasted verbatim). The pairs, the `why` sentences and the Cypher templates are the agents'; the
whitespace differs. The three graded files are the ones in this folder.
