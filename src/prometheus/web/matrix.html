How to read the matrix

Every cell is one pair of fields (the grid is symmetric, so each pair appears twice). Fields run along both edges in order of shared foundations, so related fields sit together; the clustering tree is on the top and left. Blue cells already combined, darker if newer. Fire cells have not combined but are among the pairs the graph ranks highest; a darker fire step is a higher third of the selected score. A fire cell is a ranking, not a probability. Blank cells are pairs that have not combined and are not among those shown.

Data: PatentsView (USPTO), granted US patents 1976 to 2025, grouped by CPC subclass. Stored and queried with Relate. A ranking, not a probability.
