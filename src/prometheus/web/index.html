What is this tree?

A field is a patent technology class (a CPC subclass such as H01M, batteries). 123 are shown, one dot each, bigger for more patents.

The tree groups fields by their foundations: two fields sit close together when they build on (cite) the same older fields. It is a family tree of shared foundations, not of descent, and it shows no ages, because most fields already existed when the data starts in 1976.

Solid arcs join two fields that have already combined (at least 3 patents carry both classes). Darker blue is newer; the slider moves the year, so the picture builds up. Dashed fire arcs are pairs that have not combined but that the graph ranks high. A dashed arc is a ranking, not a probability: the prediction check at the top says how far to trust it.
